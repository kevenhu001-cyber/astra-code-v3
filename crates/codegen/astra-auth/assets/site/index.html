One-line setup

Install in seconds.

Astra ships as a single static binary for Linux, macOS, and Windows — no runtime, no package manager, no dependencies.

Linux / macOS

$ curl -fsSL https://astracode.topodrive.top/install/install.sh | sh

Windows PowerShell

> irm https://astracode.topodrive.top/install/install.ps1 | iex

Then run astra login to authorize your CLI from this site, or jump straight in with astra "your first task". For source builds see the build instructions.

Questions people actually ask.

Short answers. The long ones live in the documentation.

Do I need an account?

Yes, one email address. It gates the CLI download and the per-token balance, and it is the only identity Astra keeps.

Can I self-host it?

The auth server is a single Rust binary that stores its state as JSON on disk. Point the CLI at it and it never talks to us.

Which model providers work?

Anything speaking the OpenAI chat or Responses wire format, plus Anthropic messages. DeepSeek, Qwen, OpenRouter and Ollama are configured out of the box.

What does a token cost?

Usage is metered per provider and drawn from the balance on your account page. The cost of a run is the cost of the models it touched.

Can I bring my own MCP servers?

Yes, over stdio or streamable HTTP. Point Astra at a server and it appears as a tool with the same permission model as every other one.

Does it work offline?

The runtime does. With Ollama or another local provider, a run never leaves the machine — the auth server is the only part that needs a network.
